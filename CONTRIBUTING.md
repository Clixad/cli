# Contributing

Thanks for looking. This repository is the source of the Clixad CLI, published under the Apache
License 2.0, and it works a little differently from most open source projects.

## Issues are welcome

Report bugs and suggest features in [GitHub issues](https://github.com/clixad/cli/issues), or on
[Discord](https://discord.gg/bD6FYdJfcy). For a bug, the output of `clixad --version`, your
operating system and terminal, and the steps that lead to it help the most.

## Pull requests are not accepted

Clixad is developed in a private repository. This one is an automatic one-way copy of the CLI's
part of it, rebuilt on every change, so a pull request here has nowhere to be merged. Pull requests
are closed automatically. If you have a fix in mind, describe it in an issue, with a patch or a
snippet if that is the clearest way to say it.

## Security problems

Please do not open a public issue. See [SECURITY.md](SECURITY.md).
