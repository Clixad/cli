# Security

## Reporting a vulnerability

Please email security problems to **[info@clixad.io](mailto:info@clixad.io)**.

**Do not report them in a public GitHub issue, discussion or pull request.** Anything posted there
is visible to everyone before it can be fixed.

Please say what you found and how to reproduce it, and include the version you tested
(`clixad --version`) and your operating system. We will confirm that your report arrived and keep
you updated until the fix is released. Please give us a reasonable amount of time to release a fix
before you disclose the problem publicly.

## Scope

This repository holds the Clixad CLI only. Reports about the hosted service behind it (the gateway
at app.clixad.io and the website at clixad.io) go to the same address.
