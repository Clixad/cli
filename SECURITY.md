# Security

Please report a security problem in the Clixad CLI or the service behind it privately, through
**Report a vulnerability** on this repository's [Security tab](https://github.com/clixad/cli/security),
rather than in a public issue. Include what you found, how to reproduce it, and the version
(`clixad --version`).

The CLI is the only part of Clixad in this repository. Reports about the hosted service are welcome
through the same form.
